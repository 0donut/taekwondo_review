1전처리: OpenCV로 학습용 데이터 만들기 tk_1_opencv

수업(15차시 개미/벌)은 처음부터 train/ants, train/bees처럼 정리된 데이터를 받았다. AI Hub 데이터는 큰 사진 속에 사람이 작게 있고, 정답은 파일 이름에, 위치는 json에 따로 있어서 직접 정리하는 단계가 필요했다.

① json 읽기

json_list = sorted(glob.glob(os.path.join(LABEL_ROOT, "**", "*.json"), recursive=True))  # 1,197개

for item in label["labelingInfo"]:
    if "box" in item:  box = (Xmin, Ymin, Xmax, Ymax)        # 사람 박스
    if "pose" in item: points[이름] = (int(x), int(y))        # 관절 29개

② 초록 배경 지우기 (HSV + inRange)

hsv = cv2.cvtColor(img, cv2.COLOR_BGR2HSV)
green_mask = cv2.inRange(hsv, (35, 60, 40), (85, 255, 255))   # 초록 = 흰색
person_mask = cv2.bitwise_not(green_mask)                      # 뒤집기 → 사람 = 흰색
person_mask = cv2.morphologyEx(person_mask, cv2.MORPH_OPEN, kernel)    # 점 지우기
person_mask = cv2.morphologyEx(person_mask, cv2.MORPH_CLOSE, kernel)   # 구멍 메우기

③ 윤곽선으로 사람 위치 찾기 → 라벨 박스와 비교

  • 검은 띠 때문에 사람이 위·아래 두 조각으로 잡힘 → 15×15로 크게 close해서 잇고, 화면 가장자리(카메라 장비)에 붙은 덩어리는 제외
  • OpenCV 박스와 라벨 박스의 IoU = 0.66. 라벨 박스가 사람 둘레에 여유를 두고 크게 쳐져 있어서 1이 안 나온다.

④ 정사각형으로 잘라 저장

half = int(max(x2 - x1, y2 - y1) * 1.1 / 2)     # 긴 변 기준 + 여유 10% → 찌그러지지 않게
crop = cv2.resize(img[top:bottom, left:right], (128, 128))
key = os.path.basename(json_path)[-8]            # "...-S01.json" → "S"
imwrite_kr(f"tk_crops/{CLASS_DIR[key]}/{name}", crop)
결과 tk_crops/1_start · 2_middle · 3_end에 399장씩, 총 7MB (원본 약 600MB). 폴더 이름이 곧 정답이라 datasets.ImageFolder("tk_crops") 한 줄로 읽을 수 있다. 폴더 앞에 숫자를 붙인 건 ImageFolder가 이름순으로 번호를 매기기 때문.
참고 배경 지우기·윤곽선은 OpenCV 연습용이고, 실제 저장한 사진은 json 박스로만 잘라서 배경은 초록 그대로다.

3MLP 개선: Dropout · 학습률 · Early Stopping tk_2b

여기부터 모든 실험에 Early Stopping을 넣었다. val loss가 좋아질 때마다 모델을 .pth로 저장하고, 5번 연속 안 좋아지면 멈춘 뒤 제일 좋았던 모델로 되돌린다.

if val_loss < best_loss:
    best_loss = val_loss; wait = 0
    torch.save(model.state_dict(), save_path)   # 제일 좋은 모델 저장
else:
    wait += 1
if wait >= 5: break
model.load_state_dict(torch.load(save_path))     # 끝나면 best로 되돌리기
버전Dropoutlr멈춘 / best epochval acc마지막 train acc
A 기본없음0.00112 / 70.710.91
B Dropout0.50.00120 / 150.750.77
C Dropout + lr↓0.50.000122 / 170.770.81
  • Dropout: train과 val 차이가 거의 사라짐 → 외우는 걸 막아줌. 대신 학습이 느려져서 epoch가 늘어남
  • lr↓: 가중치를 조금씩 바꿔서 val이 덜 출렁임
  • 그래도 0.77. 위치 정보를 버리는 MLP 구조 자체의 한계는 못 넘음
  • val이 264장이라 1장 = 0.4%. 약간의 출렁임은 데이터가 적어서 생기는 자연스러운 현상

4CNN 입력 크기 64 vs 128 tk_3b

"시작 ↔ 중간은 팔 높이만 조금 달라서, 사진을 크게 넣으면 더 잘 보이지 않을까?"를 확인했다. MaxPool 3번 → 크기가 1/8이 되므로 fc1 입력은 64 × (img_size // 8)²로 자동 계산.

6전이학습: ResNet18 tk_4b · 수업 14차시 방식

ImageNet(사진 120만 장, 1000종류)으로 미리 학습된 ResNet18을 가져와서 마지막 층만 3클래스로 바꿨다. 입력 224×224, ImageNet 평균·표준편차로 정규화, train에만 좌우 뒤집기.

model = models.resnet18(weights=models.ResNet18_Weights.DEFAULT)
if strategy == "freeze":
    for p in model.parameters(): p.requires_grad = False     # 전부 동결
model.fc = nn.Linear(model.fc.in_features, 3)                 # 1000 → 3 (새 층은 학습됨)

# 미세조정: 차등 학습률
optim.Adam([{"params": backbone, "lr": 0.0001},               # 이미 잘 배운 부분은 조금만
            {"params": model.fc.parameters(), "lr": 0.001}])  # 새 층은 많이
학습하는 파라미터멈춘 / best epochval acc시작 ↔ 중간 오답
A 동결1,53927 / 220.7129
B 미세조정11,178,05111 / 60.959
  • 동결이 낮은 이유: ImageNet 특징은 "강아지냐 자동차냐" 같은 물체 구분용이라, 같은 사람의 팔 높이 차이 같은 미세한 자세는 잘 못 잡음. 마지막 층(512→3) 하나만으로는 바꿀 방법이 없음
  • 미세조정이 높은 이유: 선·모양·사람 형태를 이미 아는 상태에서 백본까지 조금씩 고쳐서 태권도 자세에 맞게 다듬음
그런데 0.95를 믿어도 될까? 미세조정의 val acc가 epoch마다 0.75 ~ 0.95로 크게 출렁였는데, 그중 제일 좋은 시점을 같은 A040으로 고르고, 같은 A040으로 채점했다. 시험 문제를 보고 답을 고른 셈이라 점수가 부풀려졌을 수 있다. → 7번에서 확인

7공정한 평가: train / val / test tk_5 · tk_5b

val은 "모델 고르기(Early Stopping)"에만, test는 "마지막에 딱 한 번 채점"에만 쓴다. test는 A040으로 그대로 둬서 앞의 점수와 바로 비교했다. 비교 대상은 CNN + Dropout과 ResNet18 미세조정.

✓이번 실험에서 배운 것

  1. 전처리가 먼저다. 공공데이터는 그대로 학습에 쓸 수 없다. OpenCV로 "정답별 폴더" 모양을 만들어야 수업에서 배운 ImageFolder 방식을 쓸 수 있었다.
  2. 이미지에는 CNN. MLP는 파라미터가 12배 많아도 CNN보다 못했다. 사진을 펴는 순간 위치 정보가 사라진다.
  3. Dropout은 과적합을 줄인다. MLP(0.71→0.77)에서 효과가 크고, CNN(0.83→0.86)에서는 조금. 대신 학습이 느려진다.
  4. 입력을 키운다고 다 좋아지지 않는다. 64→128은 정확도 그대로, 계산량만 4배.
  5. 데이터가 적으면 전이학습. 미세조정은 1 epoch 만에 우리 CNN의 최종 점수에 도달했다. 단, 동결만 하면 오히려 안 좋을 수 있다 (물체 구분용 특징 ≠ 자세 구분용 특징).
  6. 고를 때 쓴 데이터로 채점하면 점수가 부풀려진다. CNN은 약 5%p. test는 마지막에 딱 한 번.
  7. val도 대표성이 중요하다. 특이한 한 사람(B002)을 val로 쓰니 Early Stopping이 2 epoch에서 멈춰 CNN이 0.56이 됐다.
  8. ±0.02 정도는 운이다. 같은 코드·seed도 GPU에서 0.83과 0.85가 나왔다. 작은 차이로 결론 내리지 않기.

?용어 정리

HSV · inRange
색을 색상(H)·채도(S)·밝기(V)로 나눈 표현. inRange는 범위 안의 색만 흰색으로 골라낸다. 초록 배경 제거에 사용.
IoU
두 박스가 겹친 넓이 ÷ 합친 넓이. 1이면 완전히 같음.
ImageFolder
폴더 이름을 정답으로 쓰는 PyTorch 데이터셋. 이름순으로 0, 1, 2 번호를 붙인다.
과적합
train은 잘 맞히는데 처음 보는 데이터는 못 맞히는 상태. train acc − val acc 차이로 확인.
Dropout
학습 때 뉴런을 무작위로 꺼서 특정 뉴런에 기대 외우는 걸 막는다. model.eval()이면 꺼진다.
Early Stopping
val loss가 정해진 횟수(patience=5) 연속 좋아지지 않으면 멈추고, 제일 좋았던 모델로 되돌린다.
전이학습
큰 데이터로 미리 학습한 모델을 가져와 우리 문제에 맞게 다시 학습. 동결 = 마지막 층만, 미세조정 = 전체를 작은 학습률로.
차등 학습률
백본은 작게(0.0001), 새 층은 크게(0.001). 이미 배운 지식을 망가뜨리지 않으려고.
train / val / test
train = 학습, val = 모델 고르기(epoch, 설정), test = 마지막 채점 한 번. test로 다시 고르면 test가 val이 되어버린다.
stratify
데이터를 나눌 때 클래스 비율을 양쪽에 똑같이 유지하는 옵션.
교차검증
test를 돌아가며 바꿔서 여러 번 평가하고 평균을 내는 방법. 데이터가 적을 때 더 믿을 만한 점수를 얻는다.
